# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of `orders-service` seriously. If you discover a potential vulnerability, please do NOT file a public issue.

Instead, please send an encrypted or direct email to the project maintainer:
- **Contact:** Alef Salu
- **Email:** security@example.com (or via private GitHub vulnerability disclosure)

Please include:
1. Detailed description of the vulnerability.
2. Steps or proof-of-concept script to reproduce.
3. Potential impact of the issue.

We will acknowledge receipt within 48 hours and work with you on a coordinated disclosure timeline.
